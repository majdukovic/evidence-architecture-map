How this map is verified

Each evidence item is a reference, repo:path:line, plus a quote copied from that line. The links open the code at the exact commit that was checked, so they keep working after the code moves on.

The map was built in three steps. First, claims were drafted from the code. Then other agents, which had not seen the draft, answered neutral questions about each claim from the code alone (Chain of Verification), and a separate reviewer tried to prove each claim wrong. Claims that did not survive were removed. Finally, a script checks every quote mechanically against each repository's default branch. Anyone can run that check again; it fails when the code changes under the map.

Links under Related links point to documents, dashboards or tickets. They are not evidence and are not checked.
